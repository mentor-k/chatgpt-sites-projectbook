같은 프롬프트·참조 이미지·해상도·품질 설정으로 비교한 뒤, 실제 작업의 품질·일관성·지연시간을 기준으로 선택하세요.

01 · 결과부터 정의

용도와 산출물을 먼저 씁니다

“예쁜 이미지”보다 제품 사진·광고·다이어그램·투명 로고처럼 결과와 사용처를 먼저 지정합니다.

02 · 장면 구조화

Scene → Subject → Composition → Style → Constraints

장면, 피사체, 구도, 재질·빛·색감, 제외 요소를 라벨로 나누면 수정과 재사용이 쉽습니다.

03 · 정확한 문구

따옴표·위치·반복 횟수

필수 문구는 “정확한 문장”으로 묶고 위치·서체·표시 횟수·추가 텍스트 금지를 함께 적습니다.

04 · 편집 지시

Change only / Preserve

바꿀 요소와 유지할 요소를 분리합니다. 얼굴·제품 형상·레이아웃·조명은 유지한다고 명시하고 한 번에 한 가지를 수정합니다.

05 · 참조 이미지 역할

입력 이미지마다 역할 부여

이미지 1은 인물, 이미지 2는 의상, 이미지 3은 배경처럼 번호와 역할을 지정하고 결합 방식을 설명합니다.

06 · 파라미터 분리

모델·품질·크기·배경

프롬프트와 별도로 model, quality, size, background를 정합니다. 투명 자산은 transparent와 PNG/WebP를 명시하고 알파 가장자리를 확인합니다.

07 · 화면비·해상도

매체에 맞는 출력

정사각형·가로·세로를 목적에 맞게 선택하고, 긴 변·픽셀 수·비율 제한을 확인합니다. 작은 글자와 복잡한 정보는 medium 이상으로 비교합니다.

08 · 결과 검수

생성 후 반드시 확인

지시 준수, 인물·제품 보존, 한글 정확성, 원치 않는 변화, 투명도와 가장자리를 확인하고 필요하면 한 항목씩 재수정합니다.
