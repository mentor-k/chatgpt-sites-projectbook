실무자 AI 엑셀 정리, 상품코드의 앞자리 0이 사라질 때 식별자와 계산값을 나눠라

영업지원·구매·재고관리 실무자의 AI 엑셀 정리: 상품코드의 앞자리 0이 사라질 때 원본과 병합 기준을 지키는 실습

김용한 박사(멘토K) · 발행 2026-11-08

핵심 답변

실무자의 AI 엑셀 정리에서 상품코드의 앞자리 0이 사라질 때는 표시를 꾸미기 전에 원본 코드와 저장된 값이 같은지 확인해야 한다. 교육담당자는 식별자와 계산값을 구분하고 상품코드 처리 규칙표·원본 대조표·병합 보류 목록으로 서로 다른 상품의 잘못된 병합을 검수하는 과제를 설계한다.

연결하면 안 되는 두 행을 먼저 준비한다

실무자의 AI 엑셀 정리 교육에서 첫 과제를 파일 병합으로 시작하지 않을 것을 제안한다. 먼저 같은 상품으로 연결하면 안 되는 두 행을 고른다. 상품코드의 앞자리 0이 사라질 때 어떤 주문이 다른 상품으로 넘어가는지 눈으로 확인할 실패 견본을 만드는 것이다. 정상적으로 연결되는 행만 시험하면 표가 완성된 뒤에도 식별 기준의 허점을 찾기 어렵다.

실패 견본에는 코드만 다른 두 상품, 코드는 같지만 공급처가 다른 두 상품을 각각 넣는다. 숫자의 모양을 보존하는 일과 그 코드가 어느 목록에 속하는지 확인하는 일은 별도 과제다. 한 공급처의 코드가 다른 공급처에서도 같은 대상을 뜻한다고 가정하지 않는다. 사내 통합코드가 없다면 어떤 항목을 조합해야 상품이 구분되는지 담당자가 먼저 정해야 한다.

가상의 교육에서 공급처 가람의 코드 0042는 노트, 같은 공급처의 42는 파일철이라고 정하자. 공급처 나루도 0042를 쓰지만 그곳에서는 봉투를 뜻한다고 가정한다. 교육용 가상 설정이다. 앞자리 0을 지우면 노트와 파일철이 섞이고, 공급처를 빼면 노트와 봉투가 섞인다. 오류의 원인이 다르므로 검사도 나눠야 한다.

코드의 모양과 소속을 따로 검수한다

상품코드 처리 규칙표의 첫 칸에는 상품을 구별할 항목의 조합을 쓴다. 가상 실습에서는 공급처와 원래 코드를 함께 사용한다. 다음 칸에는 코드 열의 저장 형식과 허용할 변환을 적는다. 수량과 금액은 계산 대상으로 두되 코드는 계산 대상에서 제외한다. 모든 코드의 길이를 맞추거나 문자를 삭제하는 처리는 별도로 승인한 규칙이 없으면 실행하지 않는다.

2026년 11월 8일 확인한 Microsoft 공식 지원 문서는 Excel에서 숫자로 해석하는 입력의 앞자리 0이 제거될 수 있으며, 텍스트 자료를 가져오는 과정에서 열을 텍스트로 지정하는 방법을 안내한다. 이 안내는 코드의 값을 유지하는 기술적 참고다. 서로 다른 공급처의 코드를 하나로 합쳐도 된다는 업무 기준까지 정해 주지는 않는다. 사용할 기능은 실제 버전에서 확인한다.

실습 파일에는 변경하지 않을 원본 영역과 작업 영역을 구분한다. 원본 대조표는 공급처·원본 코드·작업 코드·변환 규칙·검사 결과를 한 행에 둔다. 코드의 글자 수가 달라진 경우와 글자 수는 같지만 다른 공급처에 연결된 경우를 다른 오류로 표시한다. 이름이 비슷하다는 이유로 코드 충돌을 해소하지 않는다. 상품명도 변경되거나 중복될 수 있기 때문이다.

참가자는 AI에게 정리 규칙을 적용한 결과뿐 아니라 실패 견본을 어떤 행에 연결했는지 제출하도록 요청한다. 노트 주문이 파일철이나 봉투로 넘어갔다면 전체 결과의 문장을 다듬기 전에 병합을 멈춘다. 셀에 0이 다시 보이게 했다는 이유로 원래 코드가 돌아왔다고 판단하지 않는다. 현재 값만으로 이전 코드를 결정할 수 없는 행은 복구 추측 대신 확인 과제로 분리한다.

완성표에서 주문의 출발점으로 되돌아간다

검수 방향을 한 번 뒤집어 본다. 원본 주문에서 완성표를 찾는 것에 더해 완성표의 상품 하나를 골라 그 수량에 포함된 원본 주문을 펼친다. 같은 공급처와 같은 원래 코드의 주문만 모였는지 확인한다. 합계가 같아도 다른 상품끼리 수량이 바뀌어 들어갈 수 있으므로 총액 검산을 통과했다는 사실로 식별 검수를 대신하지 않는다.

병합 보류 목록에는 연결 대상 없음, 후보 여러 개, 원본 코드 확인 불가를 구분해 적는다. 각 행에 확인할 자료와 질문을 붙인다. 후보가 여러 개라면 상품 기준 목록의 중복인지 포장 단위가 빠졌는지 확인하고, 원본이 불명확하면 관리 부서가 보유한 기준 자료를 요청할 항목으로 남긴다. AI가 고른 가장 비슷한 후보를 자동 정답으로 올리지 않는다.

그다음 실패 견본의 조건을 하나씩 바꾸어 다시 검사한다. 공급처를 숨겼을 때와 앞자리 0을 지웠을 때 각각 어떤 연결이 차단되는지 본다. 교육담당자는 결과 파일의 행 수보다 참가자가 오류 원인과 중단 이유를 설명하는지 확인한다. 같은 코드라도 다른 소속이면 보류하고, 같은 소속이라도 코드가 달라졌다면 원본을 대조하는 두 판단이 구분돼야 한다.

입력자료는 실제 고객정보와 거래조건이 없는 가상 목록으로 제한한다. AI가 제안한 수식이나 변환 절차는 사본에서 시험하고 사용한 규칙과 수정 이유를 남긴다. 실제 운영 파일의 저장 방식이나 연결 기준을 바꾸는 일은 교육용 실습과 나누어 승인받는다. 외부 글의 고유 예시와 실습 양식을 가져오지 않고 현업의 구조만 반영한 새 자료를 준비한다.

실행 제안은 맞게 연결할 행과 반드시 연결을 거부할 행을 한 묶음으로 만드는 것이다. 처리 규칙표에 값 보존과 소속 확인을 나누고 원본 대조표로 왕복 추적한 뒤 병합 보류 목록의 다음 질문을 정한다. 모든 행을 채운 표보다 잘못된 연결을 거부한 이유가 남은 표가 이 교육의 완료 증거다.

코드를 예쁘게 맞추기보다 원래 대상을 그대로 구별할 수 있는지 검수하라.

이 주제의 질문과 답변

사라진 0은 자릿수를 맞춰 붙이면 되는가?

코드 길이와 부여 규칙이 확인될 때만 검토한다. 원본이나 기준 목록 없이 일정 길이로 채우면 원래 다른 코드를 새로 만들어 연결할 수 있다. 근거가 없으면 복구 대신 병합 보류로 남긴다.

병합 뒤 합계가 같으면 검수가 끝나는가?

합계 일치만으로 끝내지 않는다. 같은 수량이 다른 상품에 배정돼도 합계는 같을 수 있다. 기준 목록의 중복과 연결되지 않은 행, 여러 후보에 연결된 행을 함께 확인한다.

AI 엑셀 정리 워크숍 상담에는 무엇이 필요한가?

업무 목적과 파일 형식, 코드 부여 규칙, 병합할 목록의 관계, 사용 버전, 공개 가능한 가상 자료를 준비하면 된다. 실제 고객정보는 보내지 않고 상품코드 처리 규칙표·원본 대조표·병합 보류 목록의 실습 범위를 협의한다.
