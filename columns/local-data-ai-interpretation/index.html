상권기획자 AI 상권분석, 데이터와 현장이 다를 때 불일치를 조사 질문으로 바꿔라

상권기획자·지자체 담당자가 데이터와 현장이 다를 때 데이터 한계표와 현장 조사 질문을 연결해 활성화 대안의 적용 조건을 검토하는 실습

김용한 박사(멘토K) · 발행 2026-11-03

핵심 답변

상권기획자의 AI 상권분석에서 데이터와 현장이 다를 때는 어느 기록을 믿을지 서둘러 결정하지 말고, 불일치 번호를 붙여 확인할 상태와 경로를 구분해야 한다. 지자체 담당자는 데이터 한계표와 현장 조사 질문을 연결하고 확인된 기록만 활성화 대안 초안에 넘겨 미확인 점포 상태가 사업의 전제로 굳어지는 것을 막는다.

서로 어긋난 기록에 먼저 이름을 붙인다

상권기획자의 AI 상권분석에서 데이터와 현장이 다를 때 필요한 것은 설득력 있는 설명보다 어긋난 기록을 보존하는 절차다. 지도에는 영업 중으로 표시된 점포가 닫혀 있고, 비어 있다고 분류한 공간에는 물건이 쌓여 있을 수 있다. 현장 해석 부족을 보완한다며 그럴듯한 이유부터 붙이면 무엇을 확인해야 할지 사라진다. AI가 두 기록을 매끈한 결론으로 합치기 전에 각각의 상태와 확인 경로를 남겨야 한다.

이 글에서는 실습용 기록 이름으로 불일치 번호를 사용할 것을 제안한다. 번호마다 데이터에 적힌 상태, 현장에서 본 장면, 두 기록의 기준일, 같은 점포인지 확인할 위치 정보를 적는다. 어느 쪽도 확인 전 덮어쓰지 않는다. 예를 들어 ‘자료상 영업, 현장 셔터 닫힘’과 ‘폐업’은 다른 기록이다. 셔터가 닫혔다는 관찰은 휴무·준비 시간·이전·폐업 가운데 어느 상태인지를 아직 판정하지 못한다.

가상의 생활상권에서 공실 활용 교육을 준비한다고 가정해 보자. 오래된 점포 목록은 영업으로 분류하지만 조사일에는 간판이 사라진 공간이 있다. 다른 공간은 창문이 가려져 있으나 내부 용도를 확인하지 못했다. 이는 실제 지역이나 점포의 사례가 아니다. 두 공간을 곧바로 공실 후보로 합치지 않고 서로 다른 번호를 부여한다. 활성화 대안보다 판정을 미뤄야 할 사유를 먼저 분명히 하는 연습이다.

한 번 더 가기 전에 판정할 질문을 구분한다

데이터 한계표에는 출처와 날짜뿐 아니라 해당 자료로 판정할 수 없는 상태를 적는다. 건물 단위의 정보인지 점포 단위인지, 같은 주소의 여러 층이 구분되는지, 영업 상태의 정의와 갱신 방식이 무엇인지 실제 자료 설명에서 확인한다. 정의가 없으면 임의로 보충하지 않는다. 다른 자료의 비슷한 명칭을 같은 뜻으로 합치는 것도 보류한다. 불일치 번호를 붙여 두면 어떤 설명을 누구에게 확인할지 이어갈 수 있다.

현장 조사 질문은 재방문, 자료 제공기관 문의, 운영 주체 확인으로 나눈다. 닫힌 시각만 다른 경우에는 다른 시간에 다시 볼 필요가 있고, 분류 정의를 모르면 제공기관의 설명을 찾아야 한다. 공간 사용 여부는 허용된 범위에서 운영 주체에게 확인할 질문이다. 직접 볼 수 없는 내부를 추측하거나 무단으로 들어가지 않는다. 한 번 더 걸어 보는 일로 모든 의문이 해결되지는 않는다.

AI에는 각 불일치의 원인을 확정하게 하지 않고 현재 기록만으로 답할 질문과 추가 확인이 필요한 질문을 나누게 한다. 확인 방법을 제안받더라도 실제로 접근 가능한지 담당자가 검토한다. 제공하지 않은 점주 인터뷰와 폐업 이유, 임대 의사를 만들어 넣지 않도록 요청한다. 교육에서는 개인 이름·연락처·계약조건이 없는 가상 목록을 쓰고, 허락받지 않은 점포 사진이나 타인의 지도 이미지를 입력자료로 가져오지 않는다.

대안에는 사용할 수 있는 기록만 넘긴다

확인을 마친 기록에도 답을 얻은 항목과 여전히 모르는 항목을 구분한다. 기존 상태를 지우기보다 확인일, 방법, 확인 가능한 내용, 수정 이유를 옆에 남긴다. 다른 담당자가 같은 자료를 볼 때 판단이 달라진 경로를 알 수 있어야 한다. 상권기획자와 지자체 담당자는 결론의 문체를 다듬기 전에 어떤 불일치 번호가 해소됐고 어떤 것은 남아 있는지 함께 확인한다.

공실 활용이라는 대안을 검토할 때는 비어 보인다는 관찰만으로 공간을 사업 대상에 넣지 않는다. 실제 사용 상태와 활용 가능 여부, 운영 주체의 의사를 확인할 필요가 있다. 공간이 비어 있어도 이용 협의가 되지 않았다면 후보 검토와 실행 대상은 분리한다. 반대로 확인이 덜 됐다는 이유로 상권 전체의 구상을 멈출 필요도 없다. 확인된 범위에서 검토할 대안과 조건부로 남길 대안을 나눈다.

활성화 대안 초안에는 근거로 사용할 불일치 번호, 확인된 상태, 남은 협의, 다음 판단 시점을 연결한다. AI가 작성한 초안에 미해결 번호의 상태가 확정 표현으로 들어갔다면 해당 문장을 보류한다. 미확인 공간 수를 임의로 합산하거나 점포의 사정을 실패 원인으로 단정하지 않는다. 보고서 본문의 단정과 부록의 확인 필요 표시가 서로 모순되는지도 점검한다.

실행 제안은 공개 가능한 가상 점포 목록과 현장 메모에서 어긋난 항목을 골라 번호를 붙이는 것이다. 데이터 한계표에서 판정 불가 항목을 찾고, 현장 조사 질문마다 확인 경로를 배정한 뒤 대안 초안에 넘길 기록을 고른다. AI 상권조사·분석 워크숍에서는 다른 조가 그 번호만 따라가도 보류 이유를 설명할 수 있는지 검수한다. 교육 산출물은 확정된 활성화 사업이 아니라 확인의 순서와 적용 경계를 남긴 기록이어야 한다.

어긋난 점포 기록에 번호를 붙이고, 판정할 질문과 확인 경로를 정한 뒤 대안에 사용할 기록을 골라라.

이 주제의 질문과 답변

데이터와 현장이 다르면 현장 관찰을 우선해야 하는가?

항상 현장 관찰을 우선하지 않는다. 집계 범위·시점·대상과 관찰 조건을 비교한 뒤 무엇이 다른지 구분한다. 현장 관찰 역시 특정 구간과 시간의 기록이므로 전체 상권으로 일반화하지 않는다.

AI가 상권 활성화 대안을 바로 추천하게 해도 되는가?

아이디어 초안으로만 활용한다. 제공 자료에서 확인한 근거와 가정, 추가 조사 질문을 분리하고 운영 조건을 검토한 뒤 시험할 대안을 고른다. AI의 추천은 사업의 타당성이나 성과를 입증하지 않는다.

워크숍 상담에는 어떤 자료를 준비하면 되는가?

분석할 상권 구간과 현재 결정할 과제, 공개 가능한 자료의 설명서·기준 시점, 식별 정보를 제외한 현장 메모, 참여자 역할과 교육 시간을 준비하면 된다. 이를 바탕으로 데이터 한계표·현장 조사 질문·활성화 대안 초안의 실습 범위를 협의한다.
