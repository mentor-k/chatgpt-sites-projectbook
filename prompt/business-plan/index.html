STEP 03 · NotebookLM → Gemini Skills/Gems → ChatGPT Projects

초안 작성

NotebookLM에서 사용할 출처를 추가·선택합니다. Gemini에서 Skills 또는 편집 가능한 Gems에 지침과 자료를 저장해 여러 항목에 반복 적용합니다. ChatGPT에서는 새 프로젝트에 공동 지침과 파일을 넣고 항목별 채팅 결과를 하나로 합칩니다.

준비물 검토한 출처·제출서식다음 단계로 넘길 결과물 평가기준에 맞춘 초안

같은 자료 묶음을 세 도구에 올리기

준비: 하나의 폴더에 ① 최신 공고·제출서식 ② 심층 리서치 PDF ③ 검토한 근거표 ④ 익명화한 실증 메모를 넣습니다. 빠른 실습은 사례에서 내려받은 교육용 PDF 하나만 올려 진행하세요. 연습에서 첨부하지 않은 자료는 없는 것으로 표시합니다. 권한 없는 파일은 올리지 않습니다.

  1. NotebookLM: 새 노트북 → 소스 추가 → PDF와 원문 자료 업로드 → 사용할 소스를 선택 → 채팅에서 문서명·인용 위치를 확인합니다. 요약은 초안에 넘기되 원문을 대체하지 않습니다.
  2. Gemini Skills 또는 Gems: 개인 계정에서 Gems가 읽기 전용이면, Gemini 웹에서 맞춤설정(Customize) → Skills → 만들기(Create) → 직접 만들기(Create manually)를 엽니다. 이름·설명·지침을 쓰고 상단의 추가(Add) → 이미지 또는 파일 → PDF 선택 → 업로드 → 만들기로 저장합니다. 업무·교육 계정 등에서 Gems가 아직 편집 가능하면 Gems → 새 Gem/편집 → 지식(Knowledge) → 파일 추가 → 업로드 → 저장을 사용합니다. 둘 다 없으면 일반 Gemini 대화에 같은 지침을 붙이고 PDF를 채팅에 첨부하세요. 일반 대화의 첨부는 재사용 지침의 소스로 저장되지 않습니다.
  3. ChatGPT Projects: 새 프로젝트 → 비공개 프로젝트에 소스 추가/파일 추가 → 같은 PDF·근거표·공고·서식 업로드 → 프로젝트 설정에서 작성 지침 저장 → 새 채팅에서 파일명을 부르며 필요한 소스를 지정합니다. 파일 제한이 걸리면 우선 공식 서식과 검토한 근거표를 추가하고, 필요한 원문만 골라 첨부하세요.

초안은 확인 후 작성: 아래 업로드 확인 프롬프트를 각 도구에서 먼저 실행하고, 실제 파일명·버전·출처 하나가 맞는지 직접 대조하세요. 인용 연결이 실패하면 원문 링크와 텍스트 근거표를 다시 첨부하세요.

실습 성공 예: AI 사례 PDF를 올리면 파일명은 practice-ai.pdf, 1쪽 제목은 “제조업 견적 문의 분류 AI”, 분류는 “교육용 가상 사례”입니다. 본문에서 B-01을 확인하고, 시장 실적으로 인용하지 않아야 통과입니다.

문서 작성 지침 · 서류 제출용

공고 양식에 맞는 사업계획서 쓰기

우선순위: 최신 공식 공고·첨부서식·접수 시스템 안내 → 서식의 작성 지시 → 이 페이지의 예시. 충돌하면 임의로 해석하지 말고 공고기관에 확인하세요. 제목·순서·양식·빈칸·익명화·파일 확장자·본문 쪽수·첨부 포함 여부를 확인한 뒤 작성합니다. 글꼴·크기·줄간격·여백에 지정값이 있으면 그대로 따르세요.

구성: 평가항목을 먼저 지도에 표시

공고에 ‘문제 인식·실현 가능성·성장전략·팀 구성’이 있으면 해당 순서와 표제를 유지합니다. 일정이나 사업비를 별도로 요구하지 않으면 임의로 대항목을 만들지 말고 지정 위치에 넣으세요. 평가항목 → 해당 쪽·문단 → 근거 ID 순으로 대응표를 만듭니다. 온라인 입력은 접수 화면의 실제 글자 수와 필드를 기준으로 맞춥니다. 공고와 별첨 보는 예: 2026 예비창업패키지 2차 수정 공고(지난 공고)에서 본문·사업계획서 양식·Q&A를 각각 확인해 보세요.

문장: 읽히는 한국어로 검증 가능한 주장

문단은 핵심 주장 → 근거 → 사업상 의미 → 다음 행동 순서로 씁니다. 한 문장에는 한 가지 주장만 넣고, 다음 행동에는 담당자와 기한을 적으세요. 약어는 처음에 풀어 쓰고(예: 개념 검증, PoC), 요약·본문·예산·KPI·발표자료 모두 지표명·분모·기준일·단위를 동일하게 씁니다. 관측은 ‘확인했다’, 가정은 ‘가정한다’, 미실행은 ‘검증할 계획이다’로 구분합니다.
