공식 서식·자료 세팅

선정 또는 제출 점검 대상으로 정한 과제와 공식 자료를 가져오세요. 참여 권한 있는 비민감 자료만 업로드합니다.

준비물적격 판정표·공고·RFP·서식·근거 PDF다음 단계 산출물제출 요구와 평가항목 대응표

공고·정정 공고·RFP·별첨·접수 화면을 함께 봅니다

국가연구개발혁신법 시행규칙의 신청용·협약용 서식은 기준을 이해하는 출발점입니다. 실제 적용 방식은 해당 사업의 최신 공고·정정 공고·RFP(과제제안요구서)·개별 서식·온라인 접수 안내에서 확인하세요. 다르거나 모호할 때는 임의로 가정하지 말고 접수기관에 확인합니다. 정부지원기간, 부담금·사업비, 기술 성숙도(TRL), 성과 소유·공개 의무를 공통 수치로 가정하지 마세요.

서류 탈락 방지: 지원자격·추천·필수증빙·마감의 적격/부적격/확인 필요를 먼저 구분하세요. 결격이나 미확인은 모의 배점으로 상쇄할 수 없습니다.

NotebookLM·Gemini Skills/Gems·ChatGPT Projects에 소스 올리기

  1. NotebookLM: 새 노트북 → 소스 추가 → PDF·공고·RFP·원문 업로드 및 선택 → 채팅 구성에서 맞춤 지침을 저장할 수 있으면 저장 → 첫 채팅으로 파일 확인. 해당 메뉴가 없으면 지침을 첫 채팅에 함께 붙입니다.
  2. Gemini: Skills는 맞춤설정 → Skills → 만들기 → 직접 만들기 → 지침 작성과 상단 추가에서 PDF 선택 → 저장. Gems 편집 가능 계정은 Gems → 새 Gem/편집 → 지식 → 파일 추가 → 저장. 둘 다 없으면 일반 채팅에 파일과 지침을 함께 넣고 저장된 설정이 아님을 구분합니다.
  3. ChatGPT: 비공개 새 프로젝트 → 소스/파일 추가 → PDF·공식 문서·근거표 업로드 → 프로젝트 상단 더보기 → 프로젝트 설정에서 지침 저장 → 새 채팅으로 파일 확인. 팀 공유 전 접근권한을 확인하세요.

  • 에너지: 보정 전력 사용량 10,000에서 9,200 kWh 이하(8% 절감 목표)와 온도 충족 시간 95% 이상 모두 필요합니다. 실제 온도 기준선과 유효시간은 미확인입니다.
  • 농어업: 이탈 10/40(25%)에서 4/40(10%) 이하. 15%가 아니라 15%포인트 차이입니다.

모든 수치는 교육용 예시이며, 실제 시험·기업 성과·인증이 아닙니다.
