# AIWITH 통합 플랫폼

AIWITH는 AI 웹사이트 구축, 프롬프트, 책쓰기, 강의와 워크숍을 한 도메인 안에서 연결하는 정적 GitHub Pages 사이트입니다.

## 운영 URL

- 통합 메인: `https://aiwith.kr/`
- 웹사이트 구축 강의: `/website/`
- 웹사이트 벤치마킹: `/website/benchmark/`
- AI 프롬프트랩: `/prompt/`
- 책쓰기 스쿨: `/book-school/`
- 강의·워크숍: `/workshops/`
- AIWITH 컬럼: `/columns/`
- 공지사항: `/notices/`
- 상담 신청: `/consultation/`
- 통합 관리자 대시보드: `/admin/`

기존 강의 슬라이드와 자산은 그대로 보존합니다. 관리자 화면의 수정이력은 GitHub 최근 커밋을 자동 조회하며, 브라우저 통계와 초안은 외부 데이터 저장소 연결 전까지 해당 브라우저에 저장됩니다.
